# Selected historical sources

- [apn-sizes/](apn-sizes/README.md): original C snapshot for EA stabilizer and
  orbit counting, dependencies, recorded compiler flags, and a modern build wrapper.
- [magma/](magma/README.md): original code-equivalence scripts, input tables,
  and completed 2008 output matching the 2019 catalogue.

Original source files are preserved without edits. Each subdirectory explains
its provenance, supported reproduction checks, and known limitations.
